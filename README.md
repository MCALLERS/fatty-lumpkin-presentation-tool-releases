# Fatty Lumpkin Presentation Tool: installers

This repository holds the Mac installers for the Fatty Lumpkin Presentation Tool (FLPT), and nothing else. The source is private.

- **Download page and install steps:** https://flpt.bombadillo-ai.com (password-protected)
- **Installers:** see [Releases](../../releases).

FLPT is a preview. It isn't code-signed yet, so on first launch open **System Settings → Privacy & Security** and click **Open Anyway**.
